## 测试范围

本报告对张建国（P1-001）做 15 条固定样本的单轮直连 API 抽样，每个模型 5 条：低、中、高支持度开场，低支持度敏感请求与拒绝，低支持度长篇推销。它不是游戏 UI 内的真实多轮拜访，测试也不修改持久模型配置。每条记录呈现首次成功回复，并保留总尝试次数和失败诊断；完整原始请求/响应记录在同目录的 `requests.ndjson` 与 `responses.ndjson`。

本次配置 revision：10。所有模型共用相同的 5 段玩家输入。当前记录数：15；请求日志：15 条；响应尝试日志：15 条。

本批请求按服务端当前可用模型 ID 发送。请求模型 ID、持久配置模型 ID 与服务端返回模型 ID 分开记录；如果使用临时兼容 ID，会在该模型标题中与持久配置 ID 并列说明。本次未修改持久模型配置。

## 快速观察

本批 15 条均取得可解析正文，且每条只请求 1 次；格式成功只说明得到正文，不代表人物表现全部合格。

低支持度的开场中，豆包和 Qwen 都把话题引向“先说最关键的那一点”。Qwen 在低支持度长篇推销后也继续邀请销售方讲重点，和低支持度应更快结束拜访的设定有落差。DeepSeek 的低支持度开场与长篇推销、以及豆包的低支持度长篇推销，都出现了明确收束。

长度参考方面，DeepSeek 低支持度开场 46 字，超过本版约 40 字的低档参考；豆包低支持度敏感请求 41 字，略超同一参考。豆包高支持度开场称玩家“你”，与提示词要求的客气称谓不一致。Qwen 对敏感请求称“内部评审标准都是公开透明的”，这条输入并未提供该事实，建议避免作此断言。

DeepSeek 本次请求模型 ID 为 deepseek-flash，持久配置仍为 deepseek-v4-flash，返回 ID 为 deepseek-flash。本次临时请求选择未写回配置；本结果只说明本批请求成功，不能据此断言此前长时间无正文的根因已查明。
