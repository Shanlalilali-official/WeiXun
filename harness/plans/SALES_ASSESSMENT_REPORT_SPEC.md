## 建议报告结构

以下是基于用户目标拟定的报告建议；不构成对新评分参数或表外指标的批准。

1. 封面与测评范围、对象及日期。
2. 综合能力总览：以 C1–C6 六维雷达图呈现，并标明数据覆盖范围。
3. 六项能力详解：展示相应 B 子项、可追溯事实、优势、待提升处及可执行建议。
4. 销售风格：依据原表风格指标展示；证据不足时说明未观察。
5. 总结与行动建议：将建议关联到报告中已呈现的事实和指标。

参考 PDF 的 17 页内容顺序为：封面、概述、方法、综合六维、基础思维、执行、控单、岗位、搞事、决策、影响、销售风格、情商性格、爱情、活力、价值观、提升空间。版式可借鉴；岗位、爱情等若无原表指标和可靠输入，建议不进入默认报告。

## 指标计算与证据约束

- 目标数据链：**A 行为取值与统计口径 → B 过程指标计算 → C 汇总指标计算 → AI 解释和建议**。
- AI 负责解释已有计算结果，不能覆盖、重算或改写确定性计算出的指标分数。
- A 行为计数、观察窗口、证据归属、去重与权重仍需设计确认；本说明不自行补设。
- 缺少有效证据时标记“未观察”或“证据不足”，不得以 0 分、50 分或其他默认值冒充测评结果。
- 每个可追溯指标需保留公式/规则版本，以及支撑它的消息或事件证据 ID；无法关联证据时需明确标注。
- 评分等级、合格线和报告阈值尚未确定，不显示未经确认的评级或结论。
