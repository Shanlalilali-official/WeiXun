# 当前迭代

## 目标

完成项目一单人纵向闭环，并把原 Coze 工程迁移为可在普通本地环境运行和验证的项目。

## 已批准范围

- A：依赖、类型、lint、构建、启动、本地环境基线。
- B：AI 请求/SSE 契约、NPC 服务端画像、结构化输出。
- C：项目一五轮状态机、关系动作、解锁、结算和持久化。
- D：按对局/NPC 隔离的上下文、摘要、最近消息和 Token 控制。
- E：项目一人物、五维评分与公式问题检测。
- F：移除 Coze；建立通用 AI Provider、本地 Supabase 配置、完整迁移、seed 和环境脚本。
- G：将固定五轮改为五个15分钟项目阶段，加入服务端暂停、阶段补点、提前提交、联系人渠道与有限线下会面。
- H：将五个真实时间阶段改为五个模拟工作日，并完成邀约、预约、拜访准备/纪要、手机式前端、AI态度与礼品风险、统一幂等命令和混合结算。
- I：按 2026-08-17 流程基线改造项目一：唯一存档、四人全部显示、公开信息搜集、材料准备说明、电话/邮件自然语言邀约和条件门槛；旧规则冲突时以该基线为准。
- J：整体优化玩家端前端，先统一导航、项目入口、存档入口和游戏主工作台的视觉语言、信息层级、空状态与核心交互；延期假页面不得继续占据主导航。
- K：为项目一关键流程补充可观察数据，覆盖存档入口、公开信息、邀约结果、条件完成、材料准备、会面、阶段推进、提交和结算；区分玩家反馈与后台分析事件。
- L：对齐“给老板看”的 V1.1 流程：五段式材料大纲、邀约结果弹窗、最后一轮预警、纪要修订与原始版保留、结束当日/提交检查、竞品按日动态及结算对比。
